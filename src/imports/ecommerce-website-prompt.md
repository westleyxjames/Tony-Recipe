Professional Website Prompt – NextEra Fashion (E-commerce Clothing Brand)

Create a modern, premium ecommerce fashion website named “NextEra Fashion” targeting customers in the United States. The website sells men’s and women’s clothing including casual wear, streetwear, and modern fashion essentials.

The design should feel clean, stylish, and high-end, similar to brands like Zara or H&M.

Use large lifestyle fashion images, modern fonts, smooth animations, and a mobile-friendly responsive design.

Primary colors:

Black

White

Neutral beige / light grey
Accent color: Gold or soft blue.

The website should focus on online shopping and customer convenience.
